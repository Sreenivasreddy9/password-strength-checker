# 🔐 Password Strength Checker

A simple Python project that checks the strength of a password based on different security conditions.

## 🚀 Features

* Checks password length
* Checks for uppercase letters
* Checks for lowercase letters
* Checks for numbers
* Checks for special characters
* Calculates a password strength score
* Classifies the password as Weak, Medium, or Strong

## 🛠️ Technologies Used

* Python 3
* Python `string` module

## 📊 Password Scoring

| Condition             | Points |
| --------------------- | -----: |
| At least 8 characters |      1 |
| Uppercase letter      |      1 |
| Lowercase letter      |      1 |
| Number                |      1 |
| Special character     |      1 |

### Strength Levels

* **0–2:** Weak
* **3–4:** Medium
* **5:** Strong
